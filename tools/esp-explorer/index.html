解析说明与诊断

文件 ID 不是游戏运行时 ID。工具会根据 Master 列表识别记录的原始插件，生成“插件名 + 内部 ID”的查询代码。

ESP 中的 IDLE、AACT、IDLM 会归到动作分类。只有 IDLE 的 ENAM 字段才作为动画事件读取；Editor ID 不会被当作事件名。行为文件里的全部动作无法仅凭 ESP 列出。

可补充同语言的 .strings / .dlstrings / .ilstrings，以及 FNIS 列表、JSON 或 Papyrus 源码。配置中提取的动作均未经过游戏验证。
