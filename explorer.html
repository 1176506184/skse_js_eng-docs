ESP 资源浏览器

打开在线工具

在线版仍在浏览器本机读取你选择的文件，不上传插件。也可以从源码仓库的 tools/esp-explorer 目录离线打开 index.html，或双击打开工具.cmd。

浏览记录

选择一个 ESP / ESM / ESL，或选择单个模组文件夹。工具遍历所有记录与嵌套分组，并按道具、动作、任务、NPC 分类。

可以搜索名称、Editor ID、内部 ID、文件 ID、动作事件与来源。点击记录查看字段、任务阶段、目标、附加脚本名称；复制内部 ID 或生成的 SkyrimJS 代码。

当前筛选结果可导出 JSON 和带 BOM 的 UTF-8 CSV。CSV 对潜在公式前缀进行转义。未知记录保留通用字段与子记录签名，不等同于完整 xEdit 字段解释器。

ID 与覆盖关系

文件 ID 不是运行时 ID。工具根据 Master 列表判断原始归属；覆盖记录生成对原始插件的 import。它不合并整个游戏的加载顺序，也不猜测运行时 FE 编号。

动作来源

来源当前读取内容
IDLEENAM 事件、DNAM 文件、相关记录
AACT / IDLM显示通用记录，不把 Editor ID 当作事件
FNIS 文本常见 b / s 声明，复杂配对与序列不展开
JSON字段名含 anim / idle / event 的字符串候选
Papyrus 源码未注释的直接 SendAnimationEvent 字面量，不推导变量

候选带来源和位置，未经游戏验证。没有解析二进制 HKX、BSA/BA2、OAR/DAR 条件或动画框架运行时注册表。

本地化文本

为本地化插件补充同名同语言的 strings、dlstrings、ilstrings。缺少文本时显示字符串 ID，不把四字节编号当文本读取。界面可切换语言；旧中文插件乱码时选择 GBK。

命令行

powershell
node tools/esp-explorer/cli.cjs Example.esp --out build/Example.json --csv build/Example.csv
node tools/esp-explorer/cli.cjs Example.esp --category quests --out build/quests.json
node tools/esp-explorer/cli.cjs Example.esp --strings Example_english.strings --animations FNIS_Example_List.txt --out build/Example.json

strings 和 animations 选项可重复。还支持 type、search、encoding。退出码 0 为完成，2 为部分记录不完整，1 为读取或结构错误。

界面单插件上限 768 MiB，单记录解压上限 64 MiB。文本配置每次最多 256 份、合计 64 MiB、每份最多 8 MiB；字符串表每份最多 64 MiB。

当前解析证据

本地 MilkModNEW 样本读取了 619 条记录、55 个分组，无字段解析失败，其中 220 条道具、9 条 Idle、16 条任务。图形界面尚未启动实测，浏览器解压路径仍待操作验证。
