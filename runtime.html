运行时与生命周期

skse.onMounted(callback)

注册进入存档后的回调。在成功加载存档，或新游戏中玩家已拥有场景时调用。可注册多个回调；没有取消注册 API。

js
skse.onMounted(() => {
    const player = skse.player[0];
    // 游戏对象操作写在这里。
});

参数必须是一个函数。回调异常写入日志。新游戏场景未准备好时会记录 onMounted skipped，当前没有无限重试。

异常定位会尽可能包含实际脚本资源名和行号；内置任务代码的资源名是 skyrimjs:tasks，用户入口为 main.js。

任务状态在 onMounted 分发之前恢复，但任务回调函数必须由脚本重新注册，函数本身不写入存档。

skse.console

js
skse.console.log("数量：", 3);
skse.console.error("没有找到角色");

支持多个参数，通过 JS 字符串转换后用空格连接。error 行带有 [error]。这套日志写入 SkyrimJS.log；请使用 skse.console。

skse.runtimeVersion

只读语义的运行时版本数值，当前 0x01050610 表示项目所针对的 1.5.97。它是编码后的整数，不是十进制版本字符串。

JS 能力

入口是 ES Module，启用严格模式，顶层变量属于模块作用域。游戏入口限制 4 MiB，可处理 UTF-8 BOM。

能力当前状态
静态导入游戏插件支持 @skse/文件名.esp、.esm、.esl
相对 JS 模块尚未实现
动态 import()尚未实现
顶层 await明确拒绝
npm / require / fs / DOM未提供
Promise / async 语法V8 提供语言能力；没有通用宿主异步 I/O
setTimeout / clearTimeout宿主提供，见存储与计时器

回调中的同步异常可以记录；不要把任意返回 Promise 理解为宿主会等待它。任务、战斗和对话回调都不等待返回的 Promise。

线程与对象寿命

宿主通过 SKSE 队列进入游戏接口，并在进入 V8 时获取 isolate 锁。UI 菜单操作使用 UI 队列。

NPC、任务等句柄应在当前存档中使用。存储游戏对象依靠受支持的 ID 解析，不向 JS 暴露原生指针。角色卸载场景、死亡、删除或切换存档时，接口可能记录错误并返回 undefined。

目前只有一个入口、一个 isolate 与一个用户上下文。多模组目录、独立上下文、调试器与脚本沙箱尚未实现；只运行自己信任的脚本。
