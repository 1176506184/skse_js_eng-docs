在 Skyrim 中使用 JavaScript

SkyrimJS 是面向 Skyrim Special Edition 1.5.97 的 SKSE 插件，把 V8 嵌入游戏，通过 skse 对象向 JavaScript 提供游戏能力。

你可以创建 NPC、移动角色、管理攻击流程、展示多轮对话、查询其他插件的物品，并编写随存档保存的任务进度。

项目仍处于开发阶段。已实现不代表已完成游戏内验证。请先查看每项能力的验证状态，并在独立测试存档中尝试。

一段脚本

js
import skyrim from "@skse/Skyrim.esm";

skse.onMounted(() => {
    const player = skse.player[0];
    const gold = skyrim.getForm("0x00000F");
    if (gold) player.addItem(gold, 1);

    const task = player.addTask({
        id: "demo.hello",
        title: "初次见面",
        description: "用 JavaScript 创建的测试任务。",
    });
    skse.console.log(task.id, task.state, task.journal);
});

代码在每次进入存档时执行，例子会每次添加一枚金币。任务使用固定 ID 恢复已有进度，不会每次重复创建。

从哪里开始

  • 安装与第一个脚本：部署目录、启动方式与日志。
  • 功能与验证状态：哪些已实现，哪些仍待验证。
  • 任务与原生日志：任务目标、持久化、奖励回调。
  • ESP 资源浏览器：查找道具、动画事件和任务 ID。
  • 更新日志：代码与文档随功能一同更新。

组件如何配合

组件职责
SkyrimJS.dll承载 V8、SKSE 事件、游戏对象包装和原生接口
main.js当前唯一的用户脚本入口，以 ES Module 执行
SkyrimJS_Tasks.esp自有的轻量任务载体，向原生任务日志提供槽位
SKSE co-save保存 Storage 与 JS 任务状态，随具体存档恢复
ESP Explorer离线读取插件记录并生成查询代码
本文档站API 合同、使用限制、验证状态与发布记录

当前边界

目标版本只有 SE 1.5.97 / SKSE 2.0.20。没有声明支持 AE、VR、其他 SKSE 版本。

V8 提供 JavaScript 执行能力；当前未提供 Node.js 的 fs、require、npm 环境、浏览器 DOM 或任意网络访问接口。

本项目与游戏的 Papyrus 系统并存，尚未提供通用的跨模组 Papyrus 函数调用或任意 SKSE DLL 调用。
