插件导入与动作

import 插件

js
import milk from "@skse/MilkModNEW.esp";

skse.onMounted(() => {
    if (!milk.loaded) {
        skse.console.error(milk.name, "未加载");
        return;
    }
    const item = milk.getForm("0x016369");
    if (item) skse.player[0].addItem(item, 1);
});

模块默认导出一个只读插件对象。支持 ESP、ESM、ESL 以及带 ESL 标记的 ESP；重复导入相同文件名共享对象，ASCII 文件名忽略大小写。

成员含义
name插件文件名
loaded当前游戏加载表中是否启用该插件
getForm(localId)查询记录，成功返回 Form 包装
getStatus(eventName)生成动画事件描述

缺少插件仍可完成 import，loaded 为 false。import 不安装、不启用 ESP，也不执行其完整脚本流程。游戏插件绑定仅有默认导出；相对 JS 模块已支持静态命名/默认导出，见 JS 模组。动态导入与导入属性暂不支持。

getForm 的 ID

参数是非零整数或 0x 字符串，必须省略运行时加载编号。普通插件用低 24 位内部 ID，1.5.97 轻量插件用低 12 位。接口按当前游戏加载表组装运行时 ID；超范围直接拒绝，不截断成别的 ID。

不存在、已删除、插件未启用或参数错误时，输出错误并返回 undefined。

成功包装有只读字段：

字段类型与含义
plugin文件名字符串
localFormId内部 ID 数值
formId实际运行时 ID 数值
type原生 FormType 数值

查询得到该 ID 当前的最终覆盖记录。包装不缓存游戏指针，每次物品操作重新解析。JSON 复制、Storage 恢复的普通对象不能当作 Form 包装使用。

本地 MilkModNEW 样本里的 MME_Milk_0Generic_02 / Milk, Regular 文件 ID 为 0x03016369，内部 ID 为 0x016369。文件中的 03 属于 Master 顺序，不应当硬编码为游戏当前加载编号。不同模组版本请通过工具确认记录仍存在。

getStatus(eventName)

js
const action = milk.getStatus("MME_ZaZMOMFreeFurn_01");
if (action && player.setStatus(action)) {
    setTimeout(() => player.setStatus(skse.statusEnum.idle), 5000);
}

事件示例来自本地 ESP 的 Idle ENAM 字段，需要相应行为资源与场景条件；不保证当前角色可播放。

参数必须是 1–256 个 ASCII 字母、数字或 _ . - :。空字符串、通配符与 HKX 路径不支持；错误或插件未加载时记录错误并返回 undefined。

返回冻结描述：{ plugin, event, type: "animationEvent" }，通过私有包装标记识别，普通 JS 对象不可替代。

此方法只生成描述，不扫描或核验动作目录。动画事件属于角色行为图；插件名在这里作为可用性条件和来源标签，不表示事件只属于这个 ESP。

setStatus(action) 的结果

角色必须存活、已加载、3D 与 AI 数据可用。成功提交返回角色；动画图拒绝则写日志并返回 undefined。

animation event submitted 不证明可见动作已存在、开始或结束。骨骼、行为生成结果、家具状态、其他 AI 和动画事件都可能影响结果。

本接口只发动画事件，不启动模组任务脚本、修改任务变量、锁定输入或自动清理家具状态。完整动画框架和通用 Papyrus 调用仍未实现。动作描述可跨存档重新使用，但运行时仍会核对插件是否启用；动画跟踪与计时器不会自动恢复。
