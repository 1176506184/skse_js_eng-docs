2026-10-15 · 框架安装教程

  • 补齐游戏/SKSE 版本确认、框架文件准备、MO2、Vortex 与手动安装步骤。
  • 增加最小日志脚本、主菜单/进入存档检查和安装问题对照表。
  • 明确 DLL、脚本和任务 ESP 的职责、文件位置、单入口限制，以及修改 JS 无需重编译 DLL。
  • 说明目前没有公开 DLL 安装包；本轮只更新教程，没有发布二进制包或单独 ESP。

2026-10-15 · 完整收集任务与游戏事件

  • 新增完整山花委托示例：接取、收集、实际交付、领取 50 金币、完成与读档恢复。
  • 新增 actor.on 与可取消监听，支持 itemAdded、itemRemoved、activate、death、combatStateChanged；世界切换后清理监听。
  • 新增 actor.formId / isDead、getItemCount、removeItem、giveItem。
  • addItem 改为在游戏任务队列同步执行库存处理并核对数量差，保留成功返回角色的写法。
  • 新增 step.setProgress，用于按背包实际数量更新未完成目标。
  • 对话支持接入同一个 NPC 已经打开的菜单；仍不占用另一个 NPC 的菜单。
  • 交付/奖励示例保存结算收据，异常中断暂停盲目重试；增加有备份的示例安装器。
  • 任务核心与示例逻辑共 16 项测试通过，含部分转交异常的暂停路径。新增原生路径已编译，尚待游戏内验证。

2026-10-15 · 任务 API 与文档站

  • 任务按存档保存，相同 ID 恢复状态，换档后旧句柄失效。
  • 新增 skse.Tasks.get/list 与原生日志重试接口。
  • 新增自有 SkyrimJS_Tasks.esp 生成器，使用 32 个轻量任务槽位。
  • 原生任务标题与目标显示接入首版，尚待游戏内验证。
  • 新增中文文档站、API 合同、验证矩阵、维护与发布流程。
