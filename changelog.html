更新日志

2026-10-16 · 独立 JS 模组与安装包

  • 新增 SkyrimJS/Mods/ID/mod.json 自动发现，校验入口、依赖和所需游戏插件；拓扑排序、依赖环、缺失依赖、入口失败与依赖失败均有日志，无关模组继续加载。
  • 每个 JS 模组使用自己的 Context/globalThis，保留共享 isolate；新增静态相对 JS/MJS 导入、显式扩展名、模块缓存、循环引用及目录边界/大小上限，@skse 插件导入继续可用。
  • 新增 skse.mod，自动限定 Storage、任务 ID、任务查询、面板 ID 和 HTML 资源根；原生角色包装可在对应模组的 Storage、战斗、对话、库存和事件 API 中使用。
  • 回调与计时器保留模组归属；入口失败后停用已登记回调并尝试清理追踪资源，换档清理旧资源。普通 Context 隔离不等于执行预算或安全沙箱。
  • 旧 main.js 改为可选且默认先执行，SkyrimJS.ini 的 [Scripts] LoadLegacyMain=0 可停用；不自动迁移旧存档命名空间。
  • 新增 init/check/pack CLI 与两个独立 ZIP 示例，ZIP 直接以 SKSE 为根，不包含框架 DLL、不生成 ESP；网站提供明确列出的示例下载，未公开运行时源码或本地文件。
  • DLL 编译与独立 V8 加载器逻辑测试通过；Node 逻辑测试覆盖 manifest、命名空间、生命周期、打包和现有 UI/任务流程。未自行启动游戏或项目，实际 MO2/Vortex 安装与游戏加载待用户验证。

2026-10-16 · 快捷键与自适应随从面板

  • 新增游戏侧 skse.input.bindHotkey(chord, callback)，返回取消函数；支持 Ctrl/Alt/Shift、字母、数字、功能键及常用键，Ctrl++ 同时支持主键盘加号/等号键与小键盘加号。
  • 快捷键在没有页面时也可使用；按下触发、长按不重复，前台/世界就绪检查、回调异常记录、换档清理及旧世界排队事件过滤均已实现。
  • skse.ui.open 增加 visible、closeOnEscape，Panel 增加 visible 只读状态；随从示例默认隐藏，由 API 绑定 Ctrl++ 切换，Esc 与关闭按钮收起后可重新打开。
  • 重做随从示例的排版与卡片样式，采用 rem、视口约束、窄屏/矮屏布局和正文滚动；最大高度不超过游戏视口减去外侧留白，页头/页脚保留。
  • DLL 与 UIHost 编译通过，10 项 UI/快捷键逻辑测试通过；用户随后反馈本轮游戏内测试均正常，覆盖 Ctrl + 加号切换、Esc 收起后重新打开与新版页面。助手未自行启动游戏或项目；其他键位、尺寸和跨档场景仍待继续验证。

2026-10-16 · 启动闪退诊断

  • 本地测试反馈游戏到主菜单附近闪退；MO2 重定向日志仅显示等待 DataLoaded，尚未进入 HTML 面板或浏览器启动路径，根因待异常栈确认。
  • 增加原生阶段日志；排查版曾加入进程级异常处理器，现已撤掉，原生转储改由外部 Windows WER 收集。
  • 将 D3DCompiler 延迟到首次创建面板时加载，序列化清理在没有 UI 面板时不再提交空任务。
  • 未自动启动游戏复现，不将诊断和防护改动表述为闪退已解决。
  • 旧版对照仍退出，禁用框架后进入主菜单；原生对话 Scaleform 回调增加世界就绪检查，启动菜单不再进入影片保留/捕获任务路径，待游戏复测。
  • 战斗动作事件注册延后到 DataLoaded 之后；上述保护后的正常启动仍闪退。连接调试器的一次启动成功，用户确认透明 HTML 面板、召唤、combat/idle 与 Esc 可用，该结果不能证明正常启动已修复。
  • 临时停用原生对话注册仍闪退，现已恢复注册并移除临时 INI 选项。
  • Windows WER 转储确认排查版异常处理器在显卡工作线程异常分发时，以大栈帧递归耗尽线程栈；已移除所有进程级异常处理器，保留仅写启动阶段的日志。用户随后确认不连接调试器时主菜单及进入存档正常；该结果不代表独立定位了最初版本的全部触发条件。

2026-10-16 · 透明 HTML UI 第一阶段

  • 新增 skse.ui.open、Panel send/on/hide/show/close 与 ready/closed，最多 4 个本地页面。
  • 新增独立 CEF 宿主，通过共享内存和 D3D11 Present 合成透明画面，保存/恢复游戏渲染状态。
  • 新增基础鼠标/键盘转发、虚拟光标、玩家/菜单输入拦截与 Esc 关闭，游戏时间继续运行。
  • 页面与游戏通过受限 JSON 队列通信，游戏回调在 SKSE 游戏任务队列执行；增加页面/宿主失败、世界切换与存档清理处理。
  • 增加固定依赖下载校验、完整运行库打包和有备份安装脚本，以及血量显示、按需召唤旅人、combat/idle 的 HTML 示例。
  • DLL 和 UIHost 编译通过，6 项 UI 逻辑测试与已有 16 项回归通过。未启动项目或游戏，原生画面/输入待用户验证；未改动用户的 examples/main.js。

2026-10-15 · NPC 实例改名

  • skse.new 新增可选 name，在生成前校验文本，创建后设置该 NPC 实例的显示名。
  • 新增只读 actor.name 与 NPC setName(name)，支持已有 Storage 缓存角色改名。
  • 名称支持中文，限制 1–256 UTF-8 字节，拒绝空名字和控制字符；改名不修改共享 NPC 基础记录。
  • 名称被任务控制时保留任务数据；创建后改名失败仍返回已生成角色，避免盲目重试造成重复生成。
  • 更新收集任务示例，新生成和已有缓存的委托人显示名设为“旅人”。新增原生路径已编译，实际显示与保存/读档待验证。

2026-10-15 · 完整收集任务与游戏事件

  • 新增完整山花委托示例：接取、收集、实际交付、领取 50 金币、完成与读档恢复。
  • 新增 actor.on 与可取消监听，支持 itemAdded、itemRemoved、activate、death、combatStateChanged；世界切换后清理监听。
  • 新增 actor.formId / isDead、getItemCount、removeItem、giveItem。
  • addItem 改为在游戏任务队列同步执行库存处理并核对数量差，保留成功返回角色的写法。
  • 新增 step.setProgress，用于按背包实际数量更新未完成目标。
  • 对话支持接入同一个 NPC 已经打开的菜单；仍不占用另一个 NPC 的菜单。
  • 交付/奖励示例保存结算收据，异常中断暂停盲目重试；增加有备份的示例安装器。
  • 任务核心与示例逻辑共 16 项测试通过，含部分转交异常的暂停路径。新增原生路径已编译，尚待游戏内验证。
