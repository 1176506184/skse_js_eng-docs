原生多轮对话

启动阶段保护：SKSE 为主菜单等影片调用注册回调时，游戏世界尚未就绪则跳过影片引用和捕获任务。原生对话捕获仅在进入存档、新游戏并建立当前世界后启用。该保护针对本地启动退出的对照结果加入，具体游戏表现仍需复测。

排查中临时停用原生对话注册后仍会闪退，现已恢复完整注册流程，临时诊断配置已移除。

actor.setTopic({ target, topics })

请求 NPC 原生 Dialogue Menu。目标必须是 skse.player[0]，说话者是已加载、存活且不在战斗中的 NPC。

js
hero.setTopic({
    target: player,
    topics: [
        {
            topicText: "愿意帮我一个忙吗？",
            options: [
                { text: "你说吧。" },
                { text: "现在不行。", end: true },
            ],
        },
        {
            topicText: "帮我带一件东西回来。",
            options: [
                {
                    text: "好，我答应。",
                    onSelect: () => {
                        player.addTask({
                            id: "demo.delivery",
                            title: "帮忙送货",
                            description: "按约定带回物品。",
                        });
                    },
                },
            ],
        },
    ],
});

每个数组项是一轮。选择选项后默认进入下一项；最后一轮自动结束；end: true 提前结束。当前没有 next、节点 ID、循环跳转等分支路由。

字段

字段说明
target当前玩家包装
topics1–128 个对话轮次
topicTextNPC 台词，非空，最多 4096 UTF-8 字节
options每轮 1–16 个选项
text选项文本，非空，最多 512 UTF-8 字节
end可选布尔值，提前结束
onSelect可选同步回调

文本不能包含 NUL。先解析和校验完整配置，再请求菜单，避免一半配置触发游戏副作用。

回调时机

onSelect(e) 的 e 包含 speaker、target、round、index、text。round 和 index 从 0 开始。

中间轮次先执行回调，再推进；结束选项等原生菜单真正关闭后才执行，允许回调发起攻击或添加任务。玩家直接退出菜单不执行选项回调。异常写日志并结束当前对话。

限制与排查

同一时间只能有一个对话。当前显示字幕，不生成配音或嘴型。请求原生菜单五秒内没有得到兼容菜单时记录失败。

通过 activate 事件 开始 JS 对话时，如果游戏已打开同一个 NPC 的 Dialogue Menu，会尝试接入该菜单；另一个 NPC 的对话仍须先关闭。菜单引用保留和释放留在 UI 队列，JS 选项回调在游戏任务队列执行。此接入路径已编译，尚待实际交互验证。

实现依赖 SE 1.5.97 的原生菜单布局，修改对话 SWF 的模组可能不兼容。原生开场、镜头、输入与各类退出路径仍需游戏内验证。

setStatus(idle) 后需要让游戏 AI 状态稳定再开对话；角色重新进入战斗时可能无法开始。日志中的 setTopic: native dialogue displayed、selected option 和错误信息用于区分请求、显示和选项选择。
