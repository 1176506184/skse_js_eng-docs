存储与计时器

skse.Storage.get(key)

返回当前存档中对应的值。键不存在时返回 undefined。

skse.Storage.set(key, value)

保存 JSON 可序列化值，或框架提供的角色包装。数据写到 SKSE co-save，跟随具体存档，不是所有存档共享的磁盘配置。

js
skse.onMounted(() => {
    let hero = skse.Storage.get("myMod.hero");
    if (!hero) {
        hero = skse.new({ formId: "0x001034E4" });
        if (!hero) return;
        hero.setPosition(skse.player[0].position);
        skse.Storage.set("myMod.hero", hero);
    }
});

角色 ID 在读档时由 SKSE 重定位。已不存在的角色返回 undefined 并清理失效项。保存新角色后还要实际保存游戏，才能在下次加载恢复。

限制数值
key最多 256 UTF-8 字节
单值最多 64 KiB
总量每个存档最多 1 MiB

不保存函数、V8 上下文、计时器、攻击指令或普通对象中的原生包装身份。不要把 Form、动画描述、Task 直接 JSON 存起来再作为原生句柄使用。

任务 API 使用 __SkyrimJS.tasks.v1 与 __SkyrimJS.task.v1: 保留键，请勿手动覆盖。建议自己的键带模组前缀。当前没有公开 delete / clear / 全局配置 API。

setTimeout(callback, milliseconds)

js
const timer = setTimeout(() => {
    skse.console.log("三秒后执行");
}, 3000);

clearTimeout(timer);

返回 uint32 计时器 ID。回调必须是函数，延迟是有限数值，范围 0–3600000 ms；最多 128 个待执行计时器。小数毫秒向上取整。

计时使用墙钟，包含暂停菜单；执行仍通过 SKSE 队列，不能承诺精确帧时序。切换存档会丢弃旧计时器。当前没有 setInterval；重复工作需要自行安排下一次 setTimeout，并处理对象失效。

clearTimeout(id)

接受 uint32 ID，移除尚未执行的计时器。取消后不会调用回调；已执行或不存在的 ID 不产生额外效果。
