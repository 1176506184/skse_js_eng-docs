战斗与角色姿态

actor.setStatus(status)

js
hero.setStatus(skse.statusEnum.combat);
hero.setStatus(skse.statusEnum.idle);

combat 停止受管理的攻击流程，并保持拔出武器的姿态；它不会自动选择敌人。idle 停止战斗并收起武器，让角色回到普通游戏 AI。成功返回角色。

两种状态都会取消本框架管理的该角色攻击指令，触发其 finally。它们不会修改角色阵营或侵略性，所以游戏 AI 仍可能重新进入战斗。

如果该角色曾提交过我们的自定义动作，还会尝试发送 IdleForceDefaultState。失败写日志并允许再次调用重试。跟踪记录无法判断之后是否有其他模组接管了动画。

动画描述参数见 插件导入与动作。传入动画描述只请求动作，本身不会取消 attackTo。

actor.attackTo(target, options)

js
hero.attackTo(player, {
    dead: true,
    number: 0,
    time: 5,
    event: (e) => {
        if (player.health <= hero.attack + 10) {
            hero.setStatus(skse.statusEnum.combat);
        }
    },
    finally: (e) => {
        hero.setStatus(skse.statusEnum.idle);
        skse.console.log("攻击结束：", e.reason);
    },
});

调用者和目标都需要是当前可用且存活的角色。目标不能是自身。成功返回攻击者。游戏 AI 控制目标选择、动作与命中。

参数含义
dead为 true 时监控死亡，并在攻击者脱战时尝试重新进入战斗
number攻击动作次数上限；0 或省略关闭限制
time最长墙钟时间，秒；0 或省略关闭；最大 3600
event开始前和执行期间约每 0.5 秒调用
finally受管理流程结束时调用一次

number 计数的是 SKSE 的挥击、弓释放、法术发射等攻击动作，包含未命中的尝试。动作事件只给出攻击者，期间攻击其他目标也可能计数。

回调对象

event(e) 包含 attacker、target、count、elapsed，其中 elapsed 单位为秒。回调可以调用 setStatus(combat) 取消攻击并保持战斗姿态。

finally(e) 额外包含 reason：

reason原因
combat / idle代码调用相应姿态取消
time / number / dead达到时间、动作次数或死亡条件
replaced被同角色的新指令替换
unavailable / error对象不可用或执行失败

多个结束条件中先达到者生效。引擎结束攻击指令后保留战斗姿态；想收起武器请在 finally 中显式调用 idle。

计时使用墙钟，包含暂停菜单。换存档会丢弃旧攻击指令及回调，不在旧世界调用 finally。指令不自动保存；读档后由脚本决定是否重新下达。

低血量轮询加基础伤害参考值无法保证非致命攻击，也无法阻止已经发出的攻击造成伤害。
